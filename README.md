# Agentic AI From Zero

Notes and slides for a 2-day hands-on workshop: **Generative AI** (Day 1) and **Agentic AI** (Day 2).

**Website:** https://amitpnk.github.io/Agentic-AI-From-Zero/

| Session | Notes | Slides |
| --- | --- | --- |
| 1. How LLMs work | [notes](session-01/notes.html) | [slides](session-01/slides.html) |

## Structure

```
index.html            Workshop home page
assets/               Shared CSS and the interactive temperature demo
session-01/notes.html Session notes with examples, quiz, instructor guide
session-01/slides.html Slide deck (reveal.js)
```

## Using the slides

- `→` / `Space` next slide, `Esc` overview, `F` full screen, `S` speaker notes
- Export to PDF: open `slides.html?print-pdf` in Chrome and print to PDF

## Run locally

Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.
